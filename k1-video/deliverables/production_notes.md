## 4. 内容の編集方針の適用

- 原文の意味・条件・留保を保って話し言葉に整えた。全 93 段落と全見出しを対応表（`source_coverage.md`）で追跡し、未収録は 0 件。
- 追加していないもの：原文にない数値、排出率、治療・予防効果、商品によるプラスチック除去の主張、不安をあおる表現、確認問題・クイズ・営業案内・申込導線・制作側の説明。
- 原文にない内容として加えたのは、導入の「この講義で目指すこと」（制作指示の目的に基づく）と、各章の章扉の案内文のみ。
- 引用元の機関名は読み上げ・表示しない。文中で主張の主体になっている機関は一般名で帰属を残した（N10「ドイツの公的なリスク評価機関は…としています」、M7「欧州の食品安全の評価機関は…評価しています」）。URL は本編に出していない。
- 混同させない組み合わせを図と言葉で区別：BPA と PET／ポリカーボネート、DEP と DEHP、PET（テレフタレート）とフタル酸系可塑剤、PTFE と PFOA・PFOS、粒子と分子、接触と吸収、検出と健康影響、香料とカプセルの殻・破片、「無香料」と「マイクロカプセル不使用」。PFAS を一つの危険度で表していない。
- 根拠の種類（細胞実験・動物実験・人での関連・評価機関の判断）は形の異なるバッジで示し、同じ証拠として描いていない（第7・8章）。グラフ・数値の図は使っていない。
- 学校の理念（第1・2章）と、物質・製品の医学的効果を区別した。「排出する」は身体の働きに目を向ける視点として扱い、排出の約束・製品は描いていない。

## 8. 制作の進め方（記録）

1. 作業フォルダと既存設定を確認（既存リポジトリは LINE ボット。BP 教材のデザイン設定なし）→ 新規フォルダ `k1-video/` に制作。既存のビルドに影響しないよう、ルートの `tsconfig.json` の対象外と `.vercelignore` に追加。
2. 原文全体に段落 ID・小見出し ID を付与（`source/K1_source_with_ids.md`）。
3. scene-data（ナレーション・字幕・尺・図の段階・原文 ID・絵コンテ）を `src/data/chapters/` に集約する構成を実装。タイムライン・字幕分割・検査・静止画・書き出し・ドキュメント生成をスクリプト化。
4. 先行試作 → 章ごとの作成（並行作業、各章は独立の作業ツリー）→ 独立レビューと修正 → 統合 → 根拠の確認（並行）→ 仮音声 → 書き出し。
